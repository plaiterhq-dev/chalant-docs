Chalant documentation

Chalant is a Shopify theme for skincare and beauty brands. Its routine builder lets shoppers choose one product for each step of a routine and add the whole routine to their cart at once.

Install Chalant

  1. In your Shopify admin, go to Online Store, Themes.
  2. Add Chalant from the Shopify Theme Store. It appears in your theme library.
  3. Choose Customize to set it up. Your live store doesn't change until you publish Chalant.
  4. When you're happy with it, choose Publish.

Customize your store

Everything in Chalant is set up in the theme editor: Online Store, Themes, Customize.

  • Choose the page to edit from the menu at the top of the editor: home page, products, collections, cart, blog posts and more.
  • Add a section with Add section. Sections stack from top to bottom.
  • Add blocks inside a section to add headings, text, buttons, images and more. Drag blocks to reorder them.
  • Theme settings, under the gear icon, set your logo, fonts, colors, page width and social media links for the whole store.

Recommended first steps

  1. Logo and favicon. Theme settings, Logo. Tall logos are kept to the height of the header automatically.
  2. Colors. Theme settings, Colors. Chalant comes with five color schemes. Edit a scheme once and every section using it updates.
  3. Fonts. Theme settings, Typography. The accent font is used for single highlighted words. In any heading, make a word italic to use it.
  4. Menus. Online Store, Navigation. The header uses your main menu and supports three levels. Footer columns each use a menu you choose.
  5. Home page. Replace the example text in each section with your own, and choose a collection for Featured collection.
  6. Routine builder. Follow the routine builder guide.

    7. Animations

    Chalant moves gently as visitors scroll: the banner's images drift and fade, sections glide into place, product lineups settle, testimonial cards stack and the footer's store name rises into view. Buttons, links and product cards respond on hover.

    To turn animations off, open Theme settings, Layout and turn off Show animations. Visitors who turn off motion on their device never see animations, whatever the setting.

    Pages in Chalant

    Chalant includes layouts for every page Shopify needs, plus two extra page layouts:

    • About: an image or video beside a short introduction, then your page content. Choose it for a page under Theme template, about.
    • Contact: a contact form that uses the page's title and content as its introduction. Choose Theme template, contact.

    Editing the theme code

    Before you edit any theme code, duplicate the theme from Online Store, Themes, so you can go back if something breaks. Code changes aren't covered by support. For custom work, we recommend hiring a Shopify Partner.
