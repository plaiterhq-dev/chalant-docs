FAQ and support

Answers to common questions, and how to get help with Chalant.

Frequently asked questions

How do I change the colors?

In the theme editor, open Theme settings, Colors. Edit a color scheme and every section using it updates. Each section has a Color scheme setting to pick which scheme it uses.

Why doesn't a section show on my store?

Statistics, Testimonials and FAQ sections with no blocks, a Routine builder with no products, and a Featured collection whose collection is empty are hidden from shoppers. They still show in the theme editor so you can finish setting them up.

How do I add the routine builder to my product pages?

Open a product page in the theme editor, select the Product information section and add the Routine builder block. See the routine builder guide.

Why isn't the routine step showing on my product cards?

Tag the product with the step tag prefix and a step name, such as step:Cleanse, and check that Show routine step on product cards is on in Theme settings, Routines.

How do I show subscriptions?

Install a subscription app and add a subscription plan to the product. Purchase options appear on the product page automatically.

How do I set up filters?

Install Shopify's Search and Discovery app and choose your filters there. Turn filtering on in the Collection and Search results sections.

Can I use a different layout for one page?

Yes. In the theme editor, create a template from the page menu at the top, set it up, then choose it for the page in your admin under Theme template.

How do I translate the theme?

Go to Online Store, Themes, then the menu next to Customize, Edit default theme content. Add languages in Settings, Languages, and use the Translate and Adapt app for content.

Does Chalant work with apps?

Yes. Product pages, featured products and most sections accept app blocks. Choose Add block, Apps in the theme editor. Apps that need code changes may need help from the app developer.

How do I update Chalant?

When a new version is released, Shopify shows it in your theme library. Updating adds the new version as a copy with your settings, so you can check it before publishing.

Support

Email plaiterhq@gmail.com. So we can help quickly, include:

  • your store URL, for example your-store.myshopify.com;
  • what you expected and what happened instead, and on which page;
  • screenshots, if you can.

Support policy

  • We reply within two business days, Monday to Friday.
  • Support covers setting up and using Chalant's features and settings, and fixing anything in the theme that doesn't work as described here.
  • Support doesn't cover changes to the theme code, design work, or problems caused by third-party apps or code edits. For custom work, we recommend a Shopify Partner.
  • We fix critical bugs as soon as we find them and release updates through the Shopify Theme Store.
