Colors

Color schemes set the colors for a section or block. Each scheme has these colors: Background, Text, Secondary text, Surface, Accent, Button, Button label, Secondary button, Secondary button label. Edit a scheme once and every section using it updates.

Formula table

SettingWhat it does
The formula table shows your actives as elements, like a periodic table. Each element is a collection.
Element collectionsEach collection becomes one element, in this order. Give a collection a symbol, a strength range and a tint with its chalant.symbol, chalant.range and chalant.tint metafields. Without them the symbol is the first two letters of the collection name.
Tile styleOptions: Tinted, Outline, Mono.
Strength option nameWhen a product has an option with this name, its values show as strengths with a fill gauge.
Show the formula on product cardsReads each product's chalant.formula and chalant.ph metafields. Cards without them show the product type.
